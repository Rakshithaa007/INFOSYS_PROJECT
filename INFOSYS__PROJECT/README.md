# Creation of Intelligent Bug Diagnosis Platform with Fix Recommendation Assistance

## System Architecture

The proposed system follows an AI-powered RAG-based architecture for intelligent bug diagnosis and fix recommendation.

### System Flow

User
↓
Bug Submission Module
↓
Java Spring Boot Backend
↓
Bug Preprocessing
↓
Embedding Generation
↓
Vector Database
↓
Semantic Similarity Search
↓
RAG Pipeline + LLM
↓
Bug Diagnosis
↓
Fix Recommendation
↓
User
